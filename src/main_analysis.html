2. Data Tidying and Cleaning

Clean the surveys table by removing rows with no species ID, combining the separate year, month, and day columns into a single date, and converting sex and species ID to categorical variables.

surveys_clean <- surveys |>
  filter(!is.na(species_id)) |>
  mutate(date = make_date(year, month, day)) |>
  mutate(
    sex        = factor(sex, levels = c("M", "F")),
    species_id = factor(species_id)
  )

Count how many rows are missing values in key columns so we know what we are working with before filtering.

surveys_clean |>
  summarise(
    missing_sex             = sum(is.na(sex)),
    missing_hindfoot_length = sum(is.na(hindfoot_length)),
    missing_weight          = sum(is.na(weight))

5. Data Transformation and Species Labels

Calculate the mean weight and average hindfoot length for each species, then rank them by how commonly they appear in the dataset.

species_summary <- rodents_clean |>
  group_by(species_id, genus, species) |>
  summarise(
    mean_weight    = mean(weight),
    mean_hindfoot  = mean(hindfoot_length),
    count          = n(),
    .groups        = "drop"
  ) |>
  arrange(desc(count))

6. Visualization 1 -How is body weight distributed across the top 5 most common rodent species?

Density shows the probability of observing a rodent at a given weight. Peaks show where most individuals cluster, wider curves mean more variation.

rodents_clean |>
  filter(species_label %in% top5_species) |>
  mutate(species_label = fct_reorder(species_label, weight, median)) |>
  ggplot(aes(x = weight, fill = species_label, color = species_label)) +
  geom_density(alpha = 0.4) +
  labs(
    title = "Body Weight Distribution By Species",
    x     = "Weight (g)",
    y     = "Density",
    fill  = "Species",
    color = "Species"
  )

7. Visualization 2 - How has mean rodent body weight changed over time by species?

Calculate mean weight per year and trends over time to see how rodent body weight has changed across the study period.

rodents_clean |>
  group_by(year, species_label) |>
  summarise(
    mean_weight = mean(weight),
    .groups     = "drop"
  ) |>
  filter(species_label %in% top5_species) |>
  ggplot(aes(x = year, y = mean_weight, color = species_label)) +
  geom_line() +
  geom_point() +
  labs(
    title = "Mean Rodent Body Weight Over Time by Species",
    x     = "Year",
    y     = "Mean Weight (g)",
    color = "Species"
  )

8. Visualization 3 - Does mean body weight differ between male and female rodents across species?

Compare mean body weight between male and female rodents across the top 5 most common species to see whether weight differs by sex.

rodents_clean |>
  filter(species_label %in% top5_species) |>
  group_by(species_label, sex) |>
  summarise(
    mean_weight = mean(weight),
    .groups     = "drop"
  ) |>
  mutate(species_label = fct_reorder(species_label, mean_weight, max)) |>
  ggplot(aes(x = species_label, y = mean_weight, fill = sex)) +
  geom_col(position = "dodge") +
  scale_x_discrete(labels = function(x) str_wrap(x, width = 10)) +
  labs(
    title = "Mean Body Weight by Species and Sex",
    x     = "Species",
    y     = "Mean Weight (g)",
    fill  = "Sex"
  )
